# SpaceX Falcon 9 — Capstone Notebooks

Jupyter notebooks developed for the IBM Applied Data Science Capstone, covering the end-to-end data science workflow for Falcon 9 first-stage landing prediction.

## Notebooks

| Notebook | Purpose |
|---|---|
| [Data Collection API](jupyter-labs-spacex-data-collection-api.ipynb) | Retrieve and process historical SpaceX launch data using REST APIs. |

Additional notebooks will be documented as they are added.

## Methodology

1. Data Collection — APIs and Web Scraping
2. Data Wrangling — Cleaning and Preprocessing
3. Exploratory Data Analysis — SQL and Visualization
4. Interactive Analytics — Folium and Plotly Dash
5. Predictive Modeling — Classification and Hyperparameter Optimization

## Data

Datasets are maintained in the [data directory](../data/).

## Reproducibility

Original IBM laboratory filenames are preserved. Notebooks document their respective methods, dependencies, and execution results.
